# Built-in patterns of error lines in program output.
#
# A line starting with `+` adds a pattern of error lines. A line starting
# with `-` adds a pattern of lines that are not error lines even when a `+`
# pattern matches them, such as counters reporting zero errors. Patterns use
# the syntax of the `regex` crate and match without regard to case.

+ \b(?:error|errors|failed|failure|fatal|exception|traceback|panic|panicked|denied|cannot|unable|undefined reference)\b
+ \bFAIL\b
+ [\x{2717}\x{2716}]
+ \bnot found\b
+ No such file
+ \bwarning:
- \b0\s+(?:errors?|failed|failures?|fail)\b
