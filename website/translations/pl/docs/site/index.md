# Danaco Nurt {#danaco-nurt}

Danaco Nurt (`nurt`) to powłoka i język, w którym każdą zmianę można cofnąć.

Język działa na plikach, tekście, dokumentach strukturalnych, kodzie źródłowym, kontroli wersji, procesach i systemie operacyjnym. Program jest potokiem rekordów z typami. Każdy program jest sprawdzany przed uruchomieniem, a każde uruchomienie zwraca raport skutków.

Program wiersza poleceń `nurt` uruchamia programy w terminalu i w skryptach. Inne programy wywołują ten sam silnik jako narzędzie przez Model Context Protocol, serwer JSON-RPC lub bibliotekę.
