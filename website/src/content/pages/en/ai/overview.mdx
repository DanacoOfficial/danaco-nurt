## What installing Danaco Nurt gives

Danaco Nurt gives a model one tool in place of many shell tools. The program `nurt` runs a language in which a program is a pipeline of typed records, and the engine that runs it checks the program, performs the effect, records it and reports it. The section addresses the makers of AI models and the builders of agent engines and agent platforms. Each benefit below is a property of the product and links to the page that shows it.

## What the benefits rest on

The command catalog is the single source of the language. The engine binds every program to it, `nurt schema tool` renders the definition of the tool from it, and the training packages and the benchmark are built with the same executable. A model that is trained on the definition and the pairs therefore targets the catalog that the engine enforces, and the catalog carries a version that the host reads.

The effect of a program is known before it runs. `check` returns the strongest effect (`read`, `local`, `external` or `process`), the weakest reversibility and the paths, network targets and programs that the program names. `run` with `preview: true` lists the targets that the program would change. A host decides on this data before it calls `run`.

The result of a run is data. The report carries a status (`ok`, `planned`, `partial`, `failed`), the targets, the changes, the irreversible effects and, after a failure, the error with its code and correction. The journal turns each file change into an entry that `undo` reverts, and the call parameter `session` assigns the entry to an agent. Several agents on one tree detect each other's changes through the `etag` of every read.

## Install

Linux and macOS:

```sh
curl -fsSL https://nurt.danaco-group.pl/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://nurt.danaco-group.pl/install.ps1 | iex
```

Both installers verify the SHA-256 sum of the archive against `checksums.txt` before they place the executable. The command `nurt --version` prints the installed version, and `nurt schema tool --format anthropic` prints the first tool definition. The [platforms page](/product/platforms/) lists the archives, the packages and the container images, and the setup action for GitHub Actions is described on the [agent engines page](/ai/agent-engines/).
