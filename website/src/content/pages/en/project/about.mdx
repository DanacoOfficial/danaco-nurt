## Who builds it

Danaco Nurt is a product of Danaco Holding Group Sp. z o.o. The company holds the copyright (Copyright 2026 Danaco Holding Group Sp. z o.o., as the `NOTICE` and `README.md` of the repository state), publishes the release archives, installers and packages, and owns the names "Danaco", "Danaco Nurt" and "Danaco Holding Group". The security policy names it as the publisher of the release artifacts, and the certificate that signs `nurt.exe` is issued by the company itself.

The repository files carry a producer header with the names Danaco Official and Danaco Holding Group Sp. z o.o., the address `www.danaco-group.pl`, the GitHub organisation `DanacoOfficial` and the contact address `support@danaco-group.pl`. The sources used for this site name no other products of the company, and this page describes none. It also gives no history of the company, because no source in the repository provides one.

## What it is

Danaco Nurt is a command shell and a language where every change can be undone, built for people and AI agents. The program is `nurt`, pronounced *NOORT*. The product description in the repository sets out the design:

- one executable per operating system, for Linux, macOS and Windows;
- file, text, archive, document, code, version control, network and system operations built into the program;
- programs as pipelines of typed records, checked against the command catalog before any effect takes place;
- a structured report of the effects of every run;
- a journal of file changes that can be reviewed and undone.

The engine is a Rust library with a C interface. The repository also holds bindings for several languages (Python, Go, Node, Java and .NET have continuous integration workflows), integrations for editors and containers, a conformance suite and benchmarks. The [overview](/product/overview/) and the [architecture](/architecture/overview/) pages describe them.

## The origin of the name

*Nurt* is a Polish word for a stream or a current. The identity documents explain how the mark shows it: two chevrons, a silver one that steps back and a gold one that steps forward, are separated by a channel between their parallel arms, and that channel is the stream, in Polish *nurt*, the name of the product. The mark is also the figure of the main idea of the product: the second chevron is the first turned by 180 degrees, as an undo turns a change. The details are on the [brand](/project/brand/) page.
