## Czym jest

`nurt` (wymowa: *NURT*, polskie słowo „nurt”) to powłoka poleceń z własnym językiem do pracy z plikami, tekstem, dokumentami strukturalnymi, kodem źródłowym, kontrolą wersji, procesami i systemem operacyjnym. To jedno narzędzie dla Linuksa, Windows i macOS.

Program to potok typowanych rekordów. Każdy program jest sprawdzany przed uruchomieniem, a każde uruchomienie jest opisane ustrukturyzowanym raportem skutków. Zmiany w plikach są zapisywane w dzienniku i można je przejrzeć oraz cofnąć.

```nurt
find "/home/user/project" glob: "**/*.go"
  |> filter size > 1mb and modified > ago(24h)
  |> sort size order: desc
  |> first 20
```

Powyższy program wypisuje 20 największych plików źródłowych Go zmienionych w ciągu ostatniej doby. Każdy etap przyjmuje rekordy i zwraca rekordy; żaden nie musi analizować tekstu innego narzędzia.

Silnik jest biblioteką Rust z interfejsem C (`libnurt`, `nurt.h`). Program wiersza poleceń i serwer Model Context Protocol korzystają z tego samego silnika, tak samo może korzystać Twój własny program. Strony o [architekturze](/pl/architecture/overview/) opisują, jak części do siebie pasują.

## Dla kogo

- **Dla ludzi przy terminalu.** Powłoka, w której błędne `remove` lub `replace` można cofnąć, a program, który nie może być poprawny, jest odrzucany, zanim dotknie pliku. Zobacz [przykłady zastosowań](/pl/product/use-cases/).
- **Dla agentów AI i platform, które je uruchamiają.** Ten sam silnik jest dostępny jako narzędzie przez Model Context Protocol, serwer JSON-RPC albo bibliotekę, a każde wywołanie zwraca raport, który program potrafi odczytać. Zobacz [Nurt dla agentów AI](/pl/product/ai-agents/).
- **Dla zespołów odchodzących od basha i PowerShella.** Dokumentacja przypisuje nawyki obu powłok do ich postaci w Nurt. Zobacz [migrację](/pl/product/migration/).
