## Co daje instalacja Danaco Nurt

Danaco Nurt daje modelowi jedno narzędzie w miejsce wielu narzędzi powłoki. Program `nurt` uruchamia język, w którym program jest potokiem typowanych rekordów, a silnik, który go wykonuje, sprawdza program, wykonuje skutek, zapisuje go i raportuje. Sekcja jest adresowana do twórców modeli AI oraz do twórców silników agentów i platform agentowych. Każda korzyść poniżej jest właściwością produktu i odsyła do strony, która ją pokazuje.

## Na czym opierają się korzyści

Katalog poleceń jest jedynym źródłem języka. Silnik wiąże z nim każdy program, `nurt schema tool` generuje z niego definicję narzędzia, a paczki treningowe i benchmark powstają tym samym programem wykonywalnym. Model wytrenowany na definicji i parach celuje więc w katalog, który silnik egzekwuje, a katalog ma wersję, którą host odczytuje.

Skutek programu jest znany przed uruchomieniem. `check` zwraca najsilniejszy skutek (`read`, `local`, `external` lub `process`), najsłabszą odwracalność oraz ścieżki, adresy sieciowe i programy, które program wymienia. `run` z `preview: true` wylicza cele, które program zmieni. Host decyduje na tych danych przed wywołaniem `run`.

Wynik uruchomienia jest daną. Raport zawiera status (`ok`, `planned`, `partial`, `failed`), cele, zmiany, skutki nieodwracalne oraz, po niepowodzeniu, błąd z kodem i poprawką. Dziennik zamienia każdą zmianę plików we wpis, który `undo` cofa, a parametr wywołania `session` przypisuje wpis do agenta. Kilku agentów na jednym drzewie wykrywa wzajemne zmiany przez `etag` każdego odczytu.

## Instalacja

Linux i macOS:

```sh
curl -fsSL https://nurt.danaco-group.pl/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://nurt.danaco-group.pl/install.ps1 | iex
```

Oba instalatory weryfikują sumę SHA-256 archiwum względem `checksums.txt`, zanim umieszczą program wykonywalny. Polecenie `nurt --version` wypisuje zainstalowaną wersję, a `nurt schema tool --format anthropic` wypisuje pierwszą definicję narzędzia. [Strona platform](/pl/product/platforms/) wymienia archiwa, pakiety i obrazy kontenerów, a akcja instalacyjna dla GitHub Actions jest opisana na [stronie silników agentów](/pl/ai/agent-engines/).
